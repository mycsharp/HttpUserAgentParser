# Parser benchmarks on November 23, 2026

Release builds ran on Windows 10 x64 with an AMD Ryzen 9 9950X, .NET SDK 11.0.100 and BenchmarkDotNet 0.16.0-preview.2. Each case used a separate process, three warm-up iterations and five measurement iterations targeting 250 ms. Percentages compare mean time per uncached header within the same run. Negative values indicate less time. [Reproduction command](../../readme.md#parser-performance-on-net-11)

## Shared rule filter

For ASCII headers up to 255 characters, a single scan selects candidates for the built-in crawler, platform, device and browser rules. The parser checks those candidates in rule order. The highest-priority crawler can return before this scan. Custom crawler rules use their configured matcher. The shared lookup table occupies 64 KiB. Managed allocations per parse were the same as the previous PR on every workload measured below.

## Earlier comparison with the PR base

A second run used the same harness, inputs and job settings for the main branch at `be56445` and the reviewed parser at `1fc5d9c`. Each implementation ran in its own benchmark process. Classification differences contribute to the times, especially when a newly recognized crawler returns early.

| Workload | Main mean | PR mean | Main bytes/parse | PR bytes/parse |
| --- | ---: | ---: | ---: | ---: |
| Catalog browsers | 345.7 ns | 295.8 ns | 38 B | 38 B |
| Catalog crawlers | 389.0 ns | 174.6 ns | 2 B | 0 B |
| Full catalog | 385.8 ns | 256.4 ns | 19 B | 18 B |
| API snapshot | 438.2 ns | 321.8 ns | 29 B | 29 B |
| Googlebot | 8.336 ns | 22.486 ns | 0 B | 0 B |
| OAI-AdsBot | 797.867 ns | 265.783 ns | 0 B | 0 B |

Googlebot took 2.70 times as long in the reviewed parser, adding 14.15 ns per parse. OAI-AdsBot took about one third of the base time. All four mixed workloads were faster on the reviewed parser.

To reproduce the comparison, build the parser at `be56445` for `net11.0` in Release with `-p:AssemblyName=MyCSharp.HttpUserAgentParser.Baseline`. Set the environment variable `BenchmarkBaselineAssembly` to that DLL’s absolute path, then use the same benchmark command with the filters `"*MixedWorkloadBenchmarks.Parse*" "*HttpUserAgentParserBenchmarks.Parse*Googlebot*" "*HttpUserAgentParserBenchmarks.Parse*OAI-AdsBot*"`.
