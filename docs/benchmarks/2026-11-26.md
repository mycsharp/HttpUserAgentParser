# Parser benchmarks on November 26, 2026

Release builds ran on Windows 10 x64 with an AMD Ryzen 9 9950X, .NET SDK 11.0.100 and BenchmarkDotNet 0.16.0-preview.2. Each case ran with three warm-up iterations and five measurement iterations targeting 250 ms. Percentages compare mean time per uncached header within the same run. Negative values indicate less time. [Reproduction command](../../readme.md#run-the-benchmarks)

## Reproduction

Build `origin/main` in Release for `net11.0` with `-p:AssemblyName=MyCSharp.HttpUserAgentParser.Baseline` and set the `BenchmarkBaselineAssembly` environment variable to the absolute path of that DLL. Then run:

```shell
dotnet run --project perf/HttpUserAgentParser.Benchmarks -c Release -f net11.0 -- --filter "*MixedWorkloadBenchmarks.Parse*" "*HttpUserAgentParserBenchmarks.Parse*Googlebot*" "*HttpUserAgentParserBenchmarks.Parse*OAI-AdsBot*" "*DetectorWorkloadBenchmarks*" --job short --warmupCount 3 --iterationCount 5 --iterationTime 250 --launchCount 1
```
